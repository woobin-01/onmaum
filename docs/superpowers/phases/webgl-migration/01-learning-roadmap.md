## 1. 핵심 결정 사항 (학습 로드맵 기반, 변경 없음)

### 1.1 환경 격차 대응 — 전략 B (Tiered Shader)

| Tier | 대상 디바이스 | 성능 기준 | 효과 |
|------|---------------|-----------|------|
| **Tier 0 (베이스라인)** | 갤럭시 A53, iPhone 11 | 60fps 절대 보장, 픽셀당 **80 ops 이하** | 최소 |
| **Tier 2 (중급)** | iPhone 13, 갤럭시 S22 | 픽셀당 **150 ops 이하** | 6가지 효과 모두 |
| **Tier 1 (플래그십)** | iPhone 15+, 갤럭시 S24+ | 자유 | 자유 |

### 1.2 셰이더 작성 원칙 5개 (Week 1 암기 대상)

1. **Tier 0 픽셀당 80 ops 이하**
2. **노이즈 호출 횟수**: Tier 0 = 1회, Tier 2 = 2회, Tier 1 = 자유
3. **`sin`/`cos`/`sqrt`/`pow` 카운트 의식**
4. **분기문(`if`) 회피**, `mix`/`step` 사용
5. **큰 텍스처 회피** (256×256 이하)

| **보강** | 발표 직전 종합 검증 | Phase 1 종료 시 |

- **React 18+** / **Next.js 14+** App Router

## 2. 개요

### 2.1 학습 목표 — Phase 1 진입 가능 수준 정의

5주 후 다음을 모두 **검증 가능한 수준**으로 충족:

- react-three-fiber로 단순 3D 씬을 SSR 환경(Next.js)에서 작성 가능
- GLSL fragment shader 직접 작성 가능 (`shaderMaterial`로 R3F에 통합)
- `uniform`으로 React state를 셰이더에 전달 가능
- Perlin / Simplex noise를 1회 호출 제약 안에서 활용 가능
- 시간 기반 표면 일렁임 작성 가능
- **픽셀당 연산 비용 자가 추정 가능**
- Tier 0 (갤럭시 A53급, 4× throttling)에서 60fps 셰이더 작성 가능
- 3개 Tier 변형 셰이더 작성 가능
- 디바이스 감지(GPU renderer / `deviceMemory` / fps 측정) 가능
- `stats.js`로 fps 측정 가능
- **디자인 의도 1차 명세 완성** (6가지 시각 요소 × Tier별 표현)

### 2.2 학습 기간

- **5주**, 매일 **1.5시간** = **52.5시간**
- 주차별 분배: 약 10.5시간 / 주 (7일 × 1.5시간)
- 주차별 시간 배분(권장):
  - 학습 자료 읽기/시청: 약 3.5시간
  - 실습 과제: 약 4.5시간
  - 막힘 대응 + 학습 일지: 약 2.5시간
- **비관 시나리오**: 막힘 대응이 4시간 이상 차지하는 주가 1~2주 발생 가능 → §2.5 페이스 재조정 메커니즘으로 흡수

### 2.3 학습 진행 원칙

1. **TDD 학습** — 각 실습 과제는 "검증 가능한 결과"를 정의한 후 시작 (예: "회전하는 큐브가 화면에 보임")
2. **매주 검증** — 주차별 검증 항목을 충족해야 다음 주차 진입
3. **막힘 대응 1시간 룰** — 한 지점에 1시간 이상 막히면 자가 진단 → 검색 키워드 → 커뮤니티 → 다음 주제로 넘기고 학습 일지에 기록
4. **한국어 자료 우선** — 영어 자료는 보조 (§5.6 작성 원칙 반영)
5. **atomic commit** — 각 실습 과제 완료 시 atomic commit 권장. **학습 코드는 본 코드와 분리** (§3 Week 0 결정)
6. **학습 일지** — 매일 작성. 매주말 자가 평가(§9)에 통합

### 2.4 학습 종료 조건 (요약 — 상세 §9)

§2.1의 11개 항목 모두 충족 → Sub-Phase B (프로토타입) 진입.

미충족 시:
- **1~2개 미충족**: 1주 연장 (5주 → 6주)
- **3개 이상 미충족**: Phase 1 진입 자체 재평가

### 2.5 페이스 재조정 메커니즘 (50% 미만 시)

매주말 자가 평가(§9)에서 **이번 주 학습 진도 50% 미만** 시 다음 중 택1:
