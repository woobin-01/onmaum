## 한줄 요약
감정노동자(콜센터 상담 등)가 서버·계정 없이 기기 로컬에서 웹캠 표정을 자기기록하고, 오늘 리포트·체크인·선택적 넛지로 컨디션을 돌아보는 PWA.

## 목적·원칙 (구현 기준)
- 자기 모니터링 / 프라이버시 우선 (영상·원본은 서버로 안 보냄)
- 의료기기·진단 아님 (참고용 신호)
- IndexedDB(Dexie) + localStorage, 서버 API 키 없음

## 기술 스택
Next.js 16 · React 19 · TypeScript · Tailwind v4 · face-api.js · Dexie · Recharts · Vitest · PWA · Vercel

## 구현한 기능
1. 웹캠 표정 측정 (`/measure`) — face-api.js, 약 0.5초 간격, 통화(세션) 시작~종료 구간
2. 4감정 집계 — 기쁨·평온·슬픔·화남, 1분 단위 집계 후 IndexedDB
3. 오늘 리포트 (`/stats`) — 긍정/스트레스 축, 14일 개인 기준선, 차트
4. 체크인 — 오전/오후 자기보고로 보정
5. 넛지 — 기본 끔, 옵트인 인앱 배너·알림
6. Document PiP 오브 — 측정 중 작은 창(분석은 원 탭)
7. PWA — manifest·service worker
8. 온보딩 설문 — 첫 측정 전 4단계 · 상담전화 안내(1577-0199, 1393)
